# 傻瓜级别部署指南

这份指南写给**没怎么部署过东西的人**。不用敲很多命令，按步骤来就能跑起来。

你要部署的是一个叫 **SpendLog-Analytics（分析记账）** 的小工具：一台电脑当「服务器」，其他手机/电脑用浏览器访问同一个网址就能记账、看报表。

它只有两个特点需要你知道：

- **数据存在那台服务器电脑上**（SQLite 数据库文件），不是存在浏览器里，换浏览器/换手机数据都还在。
- **前后台都不用装第三方依赖**，后端只用 Python 自带的库，所以装起来非常省心。

---

## 一、开始前先确认三件事

1. **想清楚哪台电脑当服务器**：它最好一直开着（或至少用的时候开着），因为数据在它上面。
2. 确认那台电脑能用**浏览器**、能**上网**。
3. 手机和这台电脑最好在**同一个 WiFi / 局域网**下（这样手机才能访问；如果只想自己电脑上玩，局域网这台就无所谓）。

> 不会配置网络？没关系。默认情况下，只要手机和服务器连的是同一个 WiFi，通常就能直接访问，大多数家用路由器不需要额外设置。

---

## 二、选一种方式部署（二选一）

### 方案 A：直接跑（最简单，推荐单人/内网试用）

**只需要装 Python，不用装任何别的东西。**

1. **给服务器装 Python**
   - 去官网 https://www.python.org/downloads/ 下载。
   - Windows 装的时候，**务必勾选最底下「Add Python to PATH」那个选项**，不然找不到命令。
   - 装完在「开始菜单」里搜 `cmd`，打开一个黑色窗口（命令行）。

2. **进入项目目录**
   在黑色窗口里打：
   ```cmd
   cd /d E:\Programmes\SpendLog-Analytics
   ```
   （如果你把项目放在别的地方，把路径换成你的。）

3. **启动服务**
   在窗口里打：
   ```cmd
   python script\server.py
   ```
   看到窗口里不再报错、光标停住不动，就说明跑起来了。**这个窗口别关**，关了服务就停了。

4. **访问**
   在这台电脑浏览器地址栏输入：
   ```
   http://localhost:8090
   ```
   看到登录页就算成功了。第一次用点「注册」建账号，管理员账号是内置的 `admin / admin`。

---

### 方案 B：用 Docker（更“正式”，适合长期运行、日志隔离）

如果你电脑已经装了 Docker：
```bash
cd /d E:\Programmes\SpendLog-Analytics
docker compose up -d
```
访问方式同上（`http://localhost:8090`）。要停服务：
```bash
docker compose down
```
数据存在 Docker 卷里，卸载服务也不删数据。

---

## 三、怎么让手机也能用（局域网访问）

1. 在服务器电脑上再开一个黑色窗口，输入 `ipconfig`，找到「IPv4 地址」，形如 `192.168.1.100`。
2. 手机上连**同一个 WiFi**，打开浏览器访问：
   ```
   http://192.168.1.100:8090
   ```
3. 想更接近“App”的体验，可以在手机浏览器里把网页「添加到主屏幕」，它会变成带图标的应用（PWA，离线也能看已加载的页面）。

> 如果手机访问不了，最常见原因是**电脑防火墙拦了 8090 端口**，或者两家路由器不在同一网段。先把防火墙临时放过 8090 试试。

---

## 四、数据存在哪、怎么备份

- 所有数据都存在这台服务器**项目的 `data` 文件夹**里：
  - `data\accounts.db`：账号列表
  - `data\0.db`、`data\1.db`…：每个用户一个文件，存各自的记账数据
- **备份**：把 `data` 文件夹整个复制一份拷到U盘/网盘即可。
- **恢复**：把备份的文件放回 `data` 文件夹，重启服务。

## 五、常见问题

| 现象 | 原因与解决 |
| --- | --- |
| 页面打不开 / 连接超时 | 服务没启动，或端口被占用（未关旧窗口再开了一个）。关掉重复窗口重试；或改端口听下面说明 |
| 报 `Address already in use` | 端口被占用。换端口：`python script\server.py --port 9000`，然后访问 `http://localhost:9000` |
| 想换端口访问 | 启动命令加 `--port`，比如 `--port 9000`，浏览器就用那个端口 |
| 手机访问不了电脑 | 大概率防火墙。放行 8090 端口，并确认在同一 WiFi/网段 |
| 刷新后页面是旧的 | 这是 PWA 缓存。按 `Ctrl + F5`（Mac 用 `Cmd + Shift + R`）强制刷新 |
| 数据不见了 | 先看 `data` 文件夹是否还在、有没有被覆盖。备份过就拷回去 |

## 六、管理员 `admin` 使用提示

- 内置管理员：用户名 `admin`，初始密码 `admin`。
- 管理员是给别人开账号、管密码的，**没有记账/报表功能**。普通用户才有记账报表。
- **建议首次登录把密码改掉**（在右上角菜单里改）。改不了就是没登录进去或者不是管理员。
